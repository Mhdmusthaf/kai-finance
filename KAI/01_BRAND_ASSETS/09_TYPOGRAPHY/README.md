# KAI Typography

- **Nunito 800** — wordmark, display and headings (rounded terminals = the subtle cute cue).
- **Nunito Sans 400–800** — body, UI, every number. Use tabular + lining figures (`tnum`, `lnum`).
- Wordmark: Nunito ExtraBold, tracking −35, K/A pair −12, A/I pair +6. Always use the outlined logo files, never retype the logo.
- Money: ₹ at 62–72% of the figure size, weight 700; Indian grouping (2,48,000).

Fonts are included under the SIL Open Font License (see OFL files). Also on Google Fonts.
