KAI
Refinements Weight 800, not 900. The reference was set near Black; ExtraBold opens the A’s counter so it survives at 16 px and feels premium rather than loud. Tight, optical tracking. −35 overall, with the K/A diagonal pulled in and the I given a hair of air, so the three letters read as one confident shape. Rounded terminals stay. They echo the mascot’s soft body and leaf tip — the only “cute” cue the type carries. Always uppercase. KAI is a name, not a word. Never “Kai” or “kai” in the logo. Taglines in Nunito 700, Gray #5F6E67, set at 22% of the wordmark’s cap height.
